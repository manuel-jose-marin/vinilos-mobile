# Vinilos Mobile

App nativa Android en Kotlin para Vinilos, construida en el curso MISW-4203 Ingeniería de Software para Aplicaciones Móviles (MISO, Uniandes). Consume la API REST de [BackVynils](https://github.com/TheSoftwareDesignLab/BackVynils).
