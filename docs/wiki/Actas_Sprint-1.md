## Definition of Done (DoD)

Una historia de usuario se considerará terminada cuando cumpla con todos los siguientes criterios:

- La funcionalidad implementada satisface los criterios de aceptación definidos para la historia de usuario.
- El código fuente ha sido integrado correctamente en la rama `develop`.
- La aplicación compila y ejecuta correctamente sin errores críticos.
- Se realizó revisión por pares del código desarrollado.
- Las pruebas funcionales y automatizadas asociadas fueron ejecutadas satisfactoriamente.
- No existen defectos bloqueantes o críticos pendientes.
- La documentación técnica correspondiente fue actualizada en la wiki del proyecto.
- El issue asociado se encuentra actualizado y cerrado en GitHub Projects.
- Los cambios fueron demostrados y aceptados por el equipo durante la revisión del Sprint.
